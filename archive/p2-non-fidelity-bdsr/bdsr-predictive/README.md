# Predicting and forecasting influenza

Complete BioLang companion to BDSR chapter 10. Prepare all three declared datasets in Studio, then run cells in order. The lesson covers every section and hands-on task from 10.1 through 10.2.3, including the final pneumonia-death forecasting challenge.

The model cells perform real fitting and bootstrap assessment. They are intentionally slower than descriptive cells; the same seed and resamples are shared across algorithms so their comparison is fair.

See `ATTRIBUTION.md` for source, licence, dataset, and validation boundaries.
