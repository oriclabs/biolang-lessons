# Computational Gene-finding — a BioLang lesson

One installable Studio lesson: a BioLang port of **Computational Gene-finding**
from *A Little Book of R for Bioinformatics*.

It covers the genetic code, locating start and stop codons, reading-frame
arithmetic, open reading frames on the forward and reverse strands, translating
a candidate coding region, and judging ORF length against a null model — with
all nine exercises solved.

An ORF is a candidate, not proof of a gene. The lesson keeps that distinction
explicit: length is evidence, and real annotation also weighs conservation,
transcripts, start context, coding bias, and experiment.

The source chapter compares against randomly generated sequences without
publishing its seed or generated records. This lesson retains the exact source
figure and reported answer and does not invent a replacement dataset.

Open it in BioLang Studio, choose **Prepare all**, and run the cells in order.
